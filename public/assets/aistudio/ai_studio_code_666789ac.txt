Build an elderly-friendly anti-scam checking web application called **"JagaCare"** (Chinese title: **"JagaCare 安心查"**) using **React** (frontend) and **Node.js** (backend API for Gemini multimodal analysis), designed to help senior citizens check suspicious messages from WhatsApp, Telegram, SMS, screenshots, and voice notes before taking action.

### 5. SCREEN 2: RESULTS SCREEN

- **Loading State**: Stacked pastel card with spinner, *"Checking safely for you..."*, *"Please wait a moment. Do not reply or click anything yet."*, and a pill **"Cancel"** button.
- **Error State**: Outlined `#FEF2F2` card showing real error message + Mint Green pill **"Try Again"** button.
- **Success State** (stepped cards in order):
  1. **Media Preview** (if applicable): Uploaded screenshot preview (`max-height: 180px`) or lavender pill showing *"Checking audio: <filename>"*.
  2. **Stacked Verdict Banner Card**:
     - Colored Header Bar:
       - `STOP`: Red `#DC2626` — *"STOP — Likely a Scam. Do NOT reply, click, or pay."*
       - `WAIT`: Amber `#D97706` — *"WAIT — Looks Suspicious. Check safely first."*
       - `SAFE`: Mint Green `#5CE094` — *"NO OBVIOUS DANGER — Still never share OTP codes or transfer money to strangers."*
     - Card Body: Pill `scam_category` tag + Bold `headline` + `simple_summary`.
  3. **Pill "Read This Aloud" Button (`min-height: 60px`, `#5CE094` Mint Green; switches to `#DC2626` Red "Stop Reading" while active)**:
     - Uses **Web Speech API (`window.speechSynthesis`)** at calm `0.88` speech rate in the selected language (`en-MY`/`en-US`, `ms-MY`, `zh-CN`), reading: Verdict prefix + `headline` + `simple_summary` + all `red_flags.plain_explanation` + numbered `safe_check_steps`.
  4. **"Why This Looks Risky" Card** (or **"What We Checked"** when `SAFE`):
     - Lists each item from `red_flags`: highlighted bordered quote box (`"quoted_clue"`) + bullet `plain_explanation`.

     - Lists numbered steps from `safe_check_steps` with `34px` circular Mint Green `#5CE094` number badges.

       - *PDRM Semak Mule*: `https://semakmule.rmp.gov.my` (shown for all `STOP`/`WAIT` results and account/phone checks)

  6. **Pill Lavender `#8257E5` "Send to Family to Double-Check" Button**:

### 7. NODE.JS BACKEND & GEMINI AI ANALYSIS SPECIFICATION

- **Backend API Endpoint**: `POST /api/analyze` (accepts `multipart/form-data` or JSON with `text`, `image` file up to 20MB, or `audio` file up to 18MB, plus `language`: `en` | `ms` | `zh`). Call Gemini server-side using `@google/genai` with `GEMINI_API_KEY` from environment variables and a 60-second timeout.
- **Recommended Model**: `gemini-2.5-flash` or latest Gemini Flash multimodal model with `temperature: 0.2` and `responseMimeType: "application/json"` + strict `responseSchema`.
- **Exact System Prompt**:
  > You are JagaCare, a calm, protective, and patient scam-detection assistant built especially to protect elderly users from WhatsApp, Telegram, SMS, and social media scams in Malaysia and Southeast Asia.
  > Analyze the user's uploaded screenshot, image, audio, or pasted text for signs of fraud, impersonation, urgency manipulation, suspicious links, malicious .apk files, fake receipts, or requests for money/OTP codes.
  >
  > RULES:
  > 1. Audience & Tone: Write as if gently explaining to a 70-year-old parent. Use short, reassuring sentences. NEVER use technical jargon ("phishing", "spoofing", "malware", "social engineering", "typosquatting", "sideloading"). Always use simple words ("fake website", "trick", "harmful app file", "trying to scare you").
  > 2. Language: Reply in the language requested by the user (or match the main language of the message: English, Bahasa Melayu, or Simplified Chinese). If the message uses Manglish or mixed languages, understand it accurately and reply clearly in simple language.
  > 3. Conservative Safety: If a message asks for money, bank details, 6-digit OTP/TAC codes, installing an .apk file, or clicking an unfamiliar link with urgency, NEVER label it "SAFE". Label it "STOP" or "WAIT".
  > 4. Local Context: Recognize Malaysian entities (PDRM, LHDN, KWSP, TNB, PosLaju, J&T, Maybank, CIMB, Public Bank, RHB, Hong Leong, Touch 'n Go eWallet, NSRC 997, Semak Mule). Never invent fake bank phone numbers.
  > 5. Output ONLY valid JSON matching this exact structure:
  > ```json
  > {
  >   "verdict": "STOP" | "WAIT" | "SAFE",
  >   "headline": "Short 5-8 word headline in plain language",
  >   "scam_category": "e.g., Fake Bank Alert / Fake Police Threat / Job Scam / Hijacked Friend / Safe Message",
  >   "simple_summary": "1-2 short, calm sentences explaining what is happening.",
  >   "red_flags": [
  >     {
  >       "quoted_clue": "Exact phrase, link, or visual detail spotted in the message",
  >       "plain_explanation": "1 simple sentence explaining why this is risky"
  >     }
  >   ],
  >   "safe_check_steps": [
  >     "Step 1: Concrete, safe action the user should take before doing anything",
  >     "Step 2: Next safe verification step"
  >   ],
  >   "family_share_summary": "Short 2-sentence summary ready to send via WhatsApp to a family member asking them to double-check."
  > }
  > ```
